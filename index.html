SIC

System Inputs Controller

El sistema SIC, o System Inputs Controller (sistema de control de entradas), es un sistema que permite controlar la ejecución de los inputs realizados por los periféricos, más concretamente el teclado y el ratón.
Proporciona un contador de clics y un autoclic con varias opciones para su funcionamiento.
NO, este programa no es un keyloger.

FUNCIONALIDAD

CONTADORES

Este programa busca poder proporcionar un control sobre los clics y las pulsaciones de las teclas brindando contadores que cuentan los diferentes clics del ratón y las pulsaciones de cualquier tecla del teclado.
¿Alguna vez te preguntaste cuanto uso le das al ratón?
¿Cuantos clics haces al día? ¿Cuantas teclas pulsas al día?
¿Haces demasiados clics?¿Que tanto uso le das a tus periféricos?
El programa facilita contadores para tener un control sobre estos datos. Además, facilita un temporizador para poder tener una referencia de tiempo.

AUTOCLICKER

Este programa incluye la posibilidad de automatizar el ingreso de comandos hacia el sistema operativo.

¿Automatizar comandos? ¿Qué comandos? ¿Qué se puede automatizar?

Supongo que alguna vez has oído sobre autoclickers... ¿si?... ¿no?... bueno, en palabras simples, un autoclicker permite ejecutar múltiples clics por segundo sin tener que mover el dedo para presionar múltiples veces el clic, solo con apretar una tecla configurada por usted mismo.
El programa simula la pulsación del clic mediante comandos que interpreta y ejecuta el sistema operativo Windows.




Puede:

Configurar cual clic quiere automatizar (clic izquierdo o clic derecho).

Configurar que tecla o combinación de teclas activará el autoclic.

Indicar cuantos clics por segundo quiere hacer.

Configurar si para activar el autoclic debe mantener presionada la tecla o si al presionar se activa y al volver a presionar se desactiva.

Ver la cantidad de clics hechos con el autoclic.

Ver la cantidad de clics hechos con el autoclic desde que se inició el programa.

OPCIONES

Personalización

El programa cuenta con la posibilidad de personalizar su aspecto.
¿Cómo puede hacer esto?

Para empezar puede elegir el color de la ventana. Puede que esté familiarizado con las opciones de modo oscuro o modo claro de los navegadores, páginas web, aplicaciones móviles o Windows 10 en adelante. Este programa tiene la opción para que usted pueda sentirse cómodo al usarlo. Puede ponerlo en modo oscuro o modo claro.

En las opciones del programa, también se da a disposición un grupo de colores donde el usuario puede elegir el color que más le guste de entre las 8 opciones que tiene. La primera opción es el color por defecto del programa. Esto cambiará el color secundario de programa.

También puede cambiar el color del texto según le guste o se adapte más a sus gustos. Puede elegir entre 4 opciones.

También puede poner el tipo de letra en bold (negrita). Esto puede ayudarle a leer mejor el programa.

CONFIGURACIÓN DE FUNCIONAMIENTO

En las opciones de programa también puede cambiar una configuración importante del programa, iniciar junto con el sistema. Es importante esta función porque va a hacer que la contabilización de las teclas y los clics sea más exacto, de esta manera tiene un control del uso de sus periféricos más preciso.

Cambie el color del programa ;)

DETALLES TÉCNICOS

Este programa fue construido en el IDE (entorno de desarrollo integrado) Visual Studio 2019.
El lenguaje utilizado para la creación del programa fue (C Sharp / C#)

El programa cuenta con un instalador, este instalador creará la carpeta donde se ubicarán los archivos necesarios para el funcionamiento junto con el ejecutable del programa. También creará un acceso directo en el escritorio y configurará el programa de manera automática para que se ejecute automáticamente junto con el sistema.

En caso de que no esté habilitada la función de ejecución automática, puede habilitarla desde las opciones.

Puede deshabilitar la ejecución automática desde las opciones, de forma predeterminada estará activo.

El programa generará archivos de texto donde está instalado, en los archivos de texto registrará la información de los contadores y guardará las configuraciones del programa para que perduren en el inicio de la aplicación.

Este programa no incluye un KeyLoger. Solo registra de manera numérica las pulsaciones de las teclas y los clics sin tener en cuenta el orden ni cuándo se han hecho. Es un programa seguro.

La velocidad del autoclicker dependerá no solo de valor indicado, también dependerá de la capacidad de procesamiento del dispositivo donde esté instalado.

Actualmente solo se puede asegurar el funcionamiento correcto del programa en Windows 10.

El programa no ha sido testeado en sistemas operativos que no sean Windows 10 y tampoco a sido probado en todas las versiones de Windows 10.
